# Verse Intel

A web application for searching and viewing public Star Citizen player and organization information using the Star Citizen API.

---

## Features

- 🔍 Search Star Citizen citizens by handle
- 👤 View player profile information
- 🏢 Display organization details
- 🖼️ Citizen and organization images
- 🎥 Animated UEE-inspired interface
- 📱 Responsive layout (work in progress)

---

## Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API

---

## Project Goals

Verse Intel started as a way for me to learn modern web development while building something related to a game I enjoy.

Current goals include:

- Browser-side caching
- Animated UEE loading sequence
- Improved UI and effects
- User accounts
- Discord bot integration
- Desktop version with Electron
